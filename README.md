# Global-Tech-Job-Market-2026
A data analytics project analyzing 12,003 global technology job postings using Python, MySQL, and Power BI to uncover salary trends, job demand, high-paying locations, and in-demand technologies.

## 📊 Project Overview

This project analyzes global technology job postings to identify
salary patterns, job demand, high-paying locations, and
in-demand technologies.

The analysis uses 12,003 technology job postings.

## 🎯 Objectives

- Analyze technology job demand
- Identify the highest-paying job roles
- Identify high-paying locations
- Analyze technology demand
- Compare job demand with salary
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Power BI
- DAX
