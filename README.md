# Global-Tech-Job-Market-2026
A data analytics project analyzing 12,003 global technology job postings using Python, MySQL, and Power BI to uncover salary trends, job demand, high-paying locations, and in-demand technologies.

## 📊 Project Overview

This project analyzes global technology job postings to identify
salary patterns, job demand, high-paying locations, and
in-demand technologies.

The analysis uses 12,003 technology job postings.

## 🎯 Objectives

- Analyze technology job demand
- Identify the highest-paying job roles
- Identify high-paying locations
- Analyze technology demand
- Compare job demand with salary
- Build an interactive Power BI dashboard

## 🔍 Key Insights

- The dataset contains 12,003 technology job postings.
- The average salary is approximately $121,244.
- Senior Data Scientist and Lead Data Scientist are among
  the highest-paying job roles.
- Backend Developer has the highest number of job postings
  among the analyzed roles.
- Seattle has the highest average salary among the analyzed
  locations.
- Python is the most frequently appearing technology, with
  3,567 job postings.
- The dataset covers August 1–5, 2026, so long-term
  month-over-month trends cannot be reliably inferred.

  ## 🔬 Methodology

### 1. Data Cleaning

Python and Pandas were used to:

- Check missing values
- Check duplicate records
- Validate salary ranges
- Convert posting dates
- Calculate average salary

### 2. Exploratory Data Analysis

The dataset was analyzed by:

- Job title
- Salary
- Location
- Technology
- Job demand

### 3. SQL Analysis

MySQL was used for:

- Aggregations
- GROUP BY and HAVING
- CASE statements
- Subqueries
- CTEs
- Window functions
- Technology analysis

### 4. Visualization

Power BI was used to create a three-page interactive dashboard.
